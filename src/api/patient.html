Patient access shell

This is not a certified patient portal

There is no identity-proofing, no notification that a result or message reached you, and no WCAG or AODA claim. A chart is reached only through the signed /patient API with a live grant.

To see your record you sign in with the identity your clinic issued, then call the patient API. This page is chrome: language, landmarks, and the limits stated above.

Chart access is /patient/* with OAuth. This shell does not load a chart.
